# EXZY Intern Handbook — Tone Guide & Copy Checklist

> คู่มือกำหนด Mood & Tone สำหรับข้อความบนเว็บไซต์ EXZY Intern Handbook  
> ใช้สำหรับเขียน แก้ ตรวจ และรีไรต์ข้อความภาษาไทยบนเว็บไซต์ให้ดูเป็นมนุษย์ อ่านง่าย และไม่เหมือน AI-generated copy

---

## 1. เป้าหมายของเว็บไซต์

เว็บไซต์นี้ถูกสร้างขึ้นเพื่อช่วยให้ intern ใหม่เข้าถึงข้อมูลที่จำเป็นได้ง่ายขึ้น หลังจากจบ Orientation แล้ว intern ควรรู้ทันทีว่า:

- ต้องทำอะไรต่อ
- ต้องเช็กข้อมูลจากตรงไหน
- ต้องใช้ลิงก์หรือเอกสารอะไรบ้าง
- ถ้าสงสัยเรื่องพื้นฐาน เช่น Wi-Fi, Timesheet, Calendar, Employee Contact ต้องไปดูหน้าไหน

เว็บไซต์นี้ไม่ควรเป็นแค่ “คลังข้อมูล” แต่ควรทำให้ intern รู้สึกว่า:

> “โอเค เรามาถูกที่แล้ว เดี๋ยวเริ่มเช็กจากตรงนี้ได้เลย”

---

## 2. คาแรกเตอร์ของเว็บไซต์

เว็บไซต์ควรพูดเหมือน:

> **เพื่อนร่วมงานที่รู้ทางแล้ว และช่วยพา intern ใหม่เช็กสิ่งที่ต้องทำแบบไม่กดดัน**

เว็บไซต์นี้ไม่ใช่:

- HR ประกาศคำสั่ง
- คู่มือเอกสารยาว ๆ
- เว็บน่ารักเล่นมุกเยอะ
- เว็บขายฝันหรือสร้างแรงบันดาลใจเกินจริง
- เว็บที่ใช้คำสวยแต่ไม่บอกข้อมูลชัดเจน

เว็บไซต์นี้ควรเป็น:

- ชัดเจน
- เป็นกันเอง
- ดู professional
- อ่านแล้วเข้าใจทันที
- ให้ความรู้สึกว่า intern มีคนช่วยพาไปทีละขั้น
- มีความจัดเจนของ CI บริษัท ให้รู้ว่านี่แหละ EXZY

## 3. Mood & Tone หลัก

```text
Smart casual
Clear
Helpful
Friendly but not cute
Professional but not corporate
Warm but not over-emotional
```

สรุปเป็นภาษาไทย:

> ชัดเจน เป็นกันเองแบบมืออาชีพ อ่านง่าย ไม่แข็ง ไม่เว่อร์ และไม่ดูเหมือน AI เขียน

## 4. หลักการเขียนข้อความบนเว็บไซต์

### 4.1 เขียนให้รู้ว่าต้องทำอะไร

ข้อความควรบอก action ชัดเจน ไม่ใช่แค่บอกว่ามีข้อมูลอะไร

**ไม่ควรเขียน**

```text
ข้อมูลเกี่ยวกับปฏิทินบริษัท
```

**ควรเขียน**

```text
กด Subscribe Calendar ไว้ จะได้ไม่พลาดวันหยุดและกิจกรรมบริษัท
```

---

### 4.2 ใช้ภาษาที่ intern ใช้จริง

ควรใช้คำที่ใกล้กับสถานการณ์จริงของ intern

**ไม่ควรเขียน**

```text
เริ่มต้นเส้นทางการฝึกงานของคุณอย่างมั่นใจ
```

**ควรเขียน**

```text
เพิ่งจบ Orientation? มาเช็กสิ่งที่ต้องทำต่อกัน
```

---

### 4.3 ไม่ใช้คำกว้างเกินไป

หลีกเลี่ยงคำที่ดูดีแต่ไม่บอกอะไร เช่น “ประสบการณ์”, “ศักยภาพ”, “การเดินทาง”, “เติบโต”

**ไม่ควรเขียน**

```text
ยกระดับประสบการณ์การฝึกงานของคุณ
```

**ควรเขียน**

```text
รวมข้อมูลที่ต้องใช้บ่อยระหว่างฝึกงานไว้ที่นี่
```

---

### 4.4 ไม่ทางการเกินไป

เว็บนี้ไม่ควรฟังเหมือนเอกสารราชการหรือประกาศ HR

**ไม่ควรเขียน**

```text
กรุณาดำเนินการบันทึกเวลาปฏิบัติงานในระบบตามระยะเวลาที่กำหนด
```

**ควรเขียน**

```text
อย่าลืมกรอก Timesheet ทุกวัน และส่งสรุปตอนสิ้นเดือน
```

---

### 4.5 ไม่น่ารักเกินไป

เป็นกันเองได้ แต่ไม่ควรใช้คำที่ทำให้เว็บดูเด็กหรือเล่นเกินไป

**ไม่ควรเขียน**

```text
มาเริ่มวันแรกแบบสดใสน่ารักกันเถอะ!
```

**ควรเขียน**

```text
ก่อนเริ่มงานวันนี้ มาเช็ก 2 สิ่งที่ต้องทำก่อน
```

---

## 5. คำที่ควรหลีกเลี่ยง

คำเหล่านี้ทำให้เว็บดู AI, ดูโฆษณา หรือดูไม่ตรงกับบริบท intern handbook

```text
เริ่มต้นการเดินทาง
ก้าวแรกสู่ความสำเร็จ
ปลดล็อกศักยภาพ
เติบโตไปด้วยกัน
พร้อมออกเดินทาง
ยกระดับประสบการณ์
เติมเต็มการฝึกงาน
ศูนย์รวมข้อมูลครบวงจร
เปิดประตูสู่โอกาส
สร้างแรงบันดาลใจ
ค้นพบตัวเอง
เส้นทางแห่งการเรียนรู้
ประสบการณ์ที่น่าจดจำ
พร้อมก้าวไปข้างหน้า
```

---

## 6. คำที่ควรใช้แทน

| คำที่ควรเลี่ยง | คำที่ควรใช้แทน |
|---|---|
| เริ่มต้นการเดินทางของคุณ | เริ่มจากสิ่งที่ต้องทำวันนี้ |
| ก้าวแรกสู่ความสำเร็จ | เช็กสิ่งสำคัญก่อนเริ่มวันแรก |
| ปลดล็อกศักยภาพ | เตรียมข้อมูลให้พร้อมก่อนเริ่มงาน |
| เติบโตไปพร้อมกับเรา | ทำความรู้จักงาน ทีม และวิธีทำงาน |
| ศูนย์รวมข้อมูลครบวงจร | รวมข้อมูลที่ intern ต้องใช้ไว้ที่นี่ |
| ยกระดับประสบการณ์ | ทำให้การหาข้อมูลง่ายขึ้น |
| เติมเต็มการฝึกงาน | ใช้เป็นคู่มือระหว่างฝึกงาน |
| พร้อมออกเดินทาง | พร้อมเริ่มวันแรกหรือยัง |
| เปิดประตูสู่โอกาส | ดูข้อมูลที่ต้องรู้ก่อนเริ่มงาน |
| ประสบการณ์ที่น่าจดจำ | เรื่องราวและผลงานจาก intern รุ่นพี่ |

## 8. แนวทางการเขียนตามแต่ละหน้า

## 8.1 Home Page

### หน้าที่ของหน้า Home

หน้า Home ควรทำให้ intern รู้สึกว่าเว็บนี้เป็นจุดเริ่มต้นที่ถูกต้อง และช่วยรวมข้อมูลที่ต้องใช้ไว้ในที่เดียว

หน้า Home ไม่ควรเป็นแค่รายการเมนูทั้งหมดของเว็บ

### Mood ของหน้า Home

```text
Welcome
Useful
Clear
Not too formal
```

### ตัวอย่าง Hero Copy

#### Option 1

```text
ทุกข้อมูลที่ intern ต้องใช้ รวมไว้ให้เริ่มง่ายขึ้น
```

```text
จาก Orientation, Calendar, Timesheet ไปจนถึงข้อมูลติดต่อทีม — เปิดหน้านี้ไว้ แล้วค่อย ๆ เช็กสิ่งที่ต้องใช้ระหว่างฝึกงานได้เลย
```

#### Option 2

```text
เริ่มฝึกงานได้ง่ายขึ้น เมื่อข้อมูลอยู่ในที่เดียว
```

```text
รวมลิงก์ เอกสาร และข้อมูลสำคัญที่ intern ต้องใช้บ่อย ไม่ต้องย้อนหาในอีเมลหลายรอบ
```

#### Option 3

```text
คู่มือเริ่มต้นสำหรับ intern ใหม่
```

```text
เช็กสิ่งที่ต้องทำหลัง Orientation และสำรวจข้อมูลที่ต้องใช้ตลอดการฝึกงานได้จากที่นี่
```

### CTA แนะนำ

```text
เริ่มจากหน้า First-day
ดูข้อมูลทั้งหมด
เปิด Orientation Slides
ไปที่ Timesheet
```

## 8.2 First-day Page

### หน้าที่ของหน้า First-day

หน้า First-day คือหน้าที่ intern จะเปิดหลังจากจบ Orientation ดังนั้นต้องตอบให้ได้ทันทีว่า:

- ตอนนี้ต้องทำอะไร
- อะไรสำคัญที่สุด
- ต้องกดลิงก์ไหน
- ต้องระวังหรือต้องไม่ลืมอะไร

### Mood ของหน้า First-day

```text
Guiding
Helpful
Direct
Calm
```

### ตัวอย่าง Hero Copy

#### Option 1

```text
เพิ่งจบ Orientation? มาเช็กสิ่งที่ต้องทำต่อกัน
```

```text
ก่อนเริ่มงานวันนี้ มี 2 เรื่องสำคัญที่ควรทำให้เรียบร้อย แล้วค่อยสำรวจข้อมูลอื่น ๆ ตามลำดับ
```

#### Option 2

```text
ก่อนเริ่มวันแรก อย่าลืมเช็ก 2 เรื่องนี้ก่อน
```

```text
Subscribe Calendar และเปิด Timesheet ให้พร้อม เพื่อให้การเริ่มงานวันแรกไม่สะดุด
```

#### Option 3

```text
วันแรกไม่ต้องงง เริ่มจากตรงนี้ได้เลย
```

```text
เช็กลำดับสิ่งที่ต้องทำหลัง Orientation พร้อมลิงก์สำคัญที่ต้องใช้ระหว่างฝึกงาน
```

### ข้อความสำหรับกล่อง “2 สิ่งที่ต้องทำตอนนี้”

```text
2 สิ่งที่ต้องทำตอนนี้
```

```text
ก่อนเริ่มงานวันนี้ อย่าลืมทำ 2 อย่างนี้ให้เรียบร้อย
```

#### Task 1: Subscribe Calendar

```text
Subscribe Company Calendar
```

```text
เพิ่มปฏิทินบริษัทไว้ใน Google Calendar เพื่อดูวันหยุด กิจกรรม และวันสำคัญของบริษัท
```

#### Task 2: เปิด Timesheet

```text
Open Your Timesheet
```

```text
เปิดไฟล์ Timesheet ของตัวเองไว้สำหรับกรอกเวลาเข้า-ออกงานทุกวัน
```

## 11. หลักการตั้งหัวข้อ Section

หัวข้อควรบอกสาระสำคัญทันที ไม่ควรเป็นคำกว้าง ๆ

| หัวข้อที่ควรเลี่ยง | หัวข้อที่ควรใช้ |
|---|---|
| Information Center | ข้อมูลที่ต้องใช้บ่อย |
| Getting Started | เริ่มจากสิ่งที่ต้องทำวันนี้ |
| Resources | ลิงก์และเอกสารสำคัญ |
| Journey | ลำดับสิ่งที่ต้องเช็กหลัง Orientation |
| Experience | เรื่องราวจาก intern รุ่นพี่ |
| Contact | รายชื่อและช่องทางติดต่อ |
| Calendar | ปฏิทินบริษัทและวันสำคัญ |
| Rules | กติกาพื้นฐานที่ควรรู้ |

## 12. Prompt สำหรับให้ AI ช่วยรีไรต์ข้อความ

ใช้ prompt นี้เมื่ออยากให้ AI ช่วยแก้ข้อความบนเว็บ

```text
ช่วยรีไรต์ข้อความภาษาไทยบนเว็บไซต์ Intern Handbook นี้ให้ดูเป็นมนุษย์มากขึ้น

Context:
เว็บไซต์นี้ทำขึ้นสำหรับ intern ใหม่ของบริษัท EXZY หลังจากจบ Orientation
เป้าหมายคือช่วยรวมข้อมูลที่ intern ต้องใช้ เช่น First-day checklist, Calendar, Timesheet, Employee Contact, Orientation Slides, Rules และ FAQs

Mood & Tone:
- smart casual
- clear
- helpful
- friendly but not cute
- professional but not corporate
- warm but not over-emotional

ข้อห้าม:
- ห้ามใช้คำที่ดู AI เช่น เริ่มต้นการเดินทาง, ปลดล็อกศักยภาพ, เติบโตไปด้วยกัน, ยกระดับประสบการณ์, ศูนย์รวมข้อมูลครบวงจร
- ห้ามทำให้ภาษาทางการเกินไป
- ห้ามทำให้ภาษาน่ารักเกินไป
- ห้ามเปลี่ยนความหมายหลัก
- ห้ามเพิ่มข้อมูลที่ไม่มีอยู่จริง

สิ่งที่ต้องการ:
1. ชี้ว่าข้อความเดิมมีปัญหาอะไร
2. รีไรต์เป็นภาษาไทยที่อ่านง่ายขึ้น
3. ให้ 3 ตัวเลือก: สั้น / เป็นกันเอง / professional
4. อธิบายสั้น ๆ ว่าทำไมข้อความใหม่ดีกว่าเดิม

ข้อความเดิม:
[วางข้อความตรงนี้]
```

## 13. Prompt สำหรับใช้กับ Cursor / Claude Code / VS Code AI Plugin

ใช้เมื่ออยากให้ AI แก้ข้อความในไฟล์โค้ดโดยไม่ไปยุ่ง layout

```text
Edit only the Thai copy in this file.

Do not change:
- component structure
- layout
- className
- styling
- links
- data structure
- logic
- imports

Improve:
- clarity
- mood and tone
- human readability
- UX writing
- Thai naturalness

Use this tone:
- smart casual
- helpful
- friendly but not cute
- professional but not corporate
- clear and direct

Avoid AI-sounding Thai phrases such as:
- เริ่มต้นการเดินทาง
- ปลดล็อกศักยภาพ
- เติบโตไปด้วยกัน
- ยกระดับประสบการณ์
- ศูนย์รวมข้อมูลครบวงจร
- พร้อมก้าวไปข้างหน้า

The website is for Thai interns who just finished orientation and need to check what to do next.
Return the edited file only.
```

## 16. Final Copy Rules

ก่อนส่งงานหรือ deploy ให้ตรวจตามกฎนี้

```text
1. ทุกประโยคต้องมีเหตุผลว่าทำไมต้องอยู่ตรงนั้น
2. ถ้าประโยคไหนสวยแต่ไม่ช่วยให้เข้าใจ ให้ตัดออก
3. ใช้คำง่ายก่อนคำสวย
4. ใช้ action ก่อน slogan
5. อย่าเขียนเหมือนขายของ
6. อย่าเขียนเหมือนประกาศ HR
7. อย่าเขียนเหมือน AI สรุปจาก brief
8. ให้ intern อ่านแล้วรู้ว่าต้องทำอะไรต่อ
```
